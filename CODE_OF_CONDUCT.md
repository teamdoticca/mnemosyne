# Code of conduct

This applies to issues, pull requests, reviews, discussions, and other project spaces.

- Be respectful and constructive. Critique ideas and code, not people.
- Welcome contributors regardless of background, identity, or experience.
- Do not harass, threaten, discriminate, publish private information, or make unwanted personal contact.
- Respect maintainer decisions and other participants' time. Disagreements should remain technical and civil.

The current maintainer is [@doticca](https://github.com/doticca). For conduct concerns, request a private contact channel from the maintainer without posting sensitive details, or use GitHub's reporting tools for abusive content. Do not use security advisories for non-security conduct reports.

Maintainers may edit or remove inappropriate content, close discussions, warn participants, or restrict participation. Responses should be proportional to the incident and protect the privacy of those involved. Concerns about a moderation decision can be raised with the maintainer; platform-level abuse can be escalated to GitHub Support.
